# Study Hub v0.5 — UI Polish 4

This is a focused visual/navigation increment on top of UI Polish 3. It does not modify API routes, Firestore schema, focus duration calculations, progress metrics, task completion timing, or the approved populated card layouts.

## Photo-driven empty states

Five static, local WebP photographs under `web/public/empty-states/`:
- `home.webp`: desk, books, warm sunlight
- `study.webp`: textbooks and journal at sunset
- `tasks.webp`: handwritten task checklist
- `calendar.webp`: desk calendar and twilight view
- `resources.webp`: books and headphones

`PhotoEmptyState` is a reusable presentation component. Only render it when the corresponding list/data collection is empty. In particular:
- **Home:** no study-course work; or no priorities in the unfiltered view (avoid duplicate photos when both empty)
- **Study:** no registered semester or no active course in the selected semester; empty dedicated Course Library/Week Resources tabs
- **Tasks:** no tasks in the selected task view
- **Calendar:** no planned or due items on the selected date (the calendar grid and the unscheduled inbox remain)
- **Resources:** no linked resources with Drive disconnected, or no discovered backup PDFs; an empty filtered subset shows a different, plain message

Photos are decorative (`alt=""`), responsive, locally hosted, and have no parallax, external fetches, looping animation, or animation-driven rerenders. The lightweight media component uses `next/image` for size optimization and responsive loading. Important actions remain real buttons connected to existing dialogs/handlers. Archived courses never expose a new Add resource action.

## Home course-card ellipsis

- The ellipsis opens a real three-item context menu, not a generic navigation shortcut.
- **View course tasks** opens the selected course's Study Tasks tab.
- **Start focus session** starts the current Focus mode for the selected course (or opens the already active session if one exists), via the existing timer logic.
- **Open course library** opens the selected course's Course Library tab.
- Menu is portaled into the app shell so the horizontally scrollable course carousel cannot clip it.
- Dismiss on outside click, scrolling, and Escape; keyboard Up/Down/Home/End navigation, focus on first item; aria menu labels.
- Normal Open course button is unchanged.

## Preview acceptance checklist

1. Open Home with no scheduled course activities. Photo appears, Create task opens the task form, and Open calendar opens the selected day.
2. Add a task: photo is replaced by real content with no overlay, image, or layout regression.
3. Switch to Study with no semesters, then with an empty semester; verify Add semester and Add course actions.
4. Open empty Course Library and Week Resources. Verify Add resource; verify archived courses have no Add resource action.
5. Open Tasks Today, Upcoming, and Completed when each is empty. Verify New task action.
6. Select an empty calendar date. Verify photo appears without replacing the calendar grid or unscheduled inbox. Pick a populated date and verify original schedule.
7. Test Resources in disconnected and connected states, including a populated Drive index with a filter showing no matches.
8. On a populated Home course card, open ellipsis. Verify click outside, Escape, Arrow keys, menu visual unclipped near screen bottom, and each of the three course-specific actions.
9. Test all five photo states at laptop/mobile widths and dark/light themes; check reduced motion preferences.
10. Verify no new errors on refresh, no course navigation mismatch, no double Focus sessions, and no regressions to tasks and progress animation.

Production merge remains subject to successful Next.js build, Vercel Preview acceptance, and real Firebase testing.
