# Study Hub v0.5 — UI Polish 2 (progress animation)

Scope: presentation-only. This increment follows UI1 + UI1a on the stable Phase D baseline.

- Course summary, Study weekly checklist, Home study-course cards, and Focus weekly goal use an accessible shared progress meter.
- Displayed percentages and focus-hours statistics animate to changed values over 450ms. The authoritative number and ARIA value update immediately.
- Progress uses **canonical optimistic task items**, not the UI1 checklist hold projection. This lets the bar advance while the completed row stays visible for the microanimation.
- At 100%, a single short sage highlight plays on the affected course/goal card. It does not replay when unchanged data rerenders or when a completed course mounts at 100%.
- Course changes and week navigation key the affected meters so an unrelated course does not animate from the previously viewed course's progress.
- Reduced-motion users get instant values without the milestone effect.
- No Firestore models, backend endpoints, resources, focus timing, images, or page layout are changed.

Preview checks: Complete/undo a task on Study and Home; observe the checkbox hold and immediate percent increase. Repeat at 100% and verify the celebration runs once. Switch courses and weeks. On Focus, finish a session and check the weekly goal bar and hour statistics. Repeat with reduced motion enabled and dark/light themes.
