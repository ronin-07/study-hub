# Study Hub v0.5 — UI Polish 4a: photo overlays and asset reliability

Apply on top of the existing UI Polish 4 code on `feature/v0.5-tasks-calendar`.

## Scope

- Changed all five photographic empty states to **one integrated photo-backed card**: icon, title, description and existing actions appear inside the image surface with a dark/plum bottom gradient.
- Replaced `next/image` for these decorative empty-state backgrounds with direct `/empty-states/<scene>.webp` CSS public-asset references. This avoids an extra `/_next/image` optimization request; a failed photo request leaves a legible plum-gradient card with no broken `<img>` placeholder.
- Retained Home, Study, Tasks, Calendar, Resources conditional rendering and existing CTAs. Home course three-dot menu remains unchanged.
- Preserved compact cards, responsiveness, reduced-motion settings, and existing populated-card layouts.
- Rebundled all **five** WebP images even though the source image contents are unchanged, because missing/untracked `web/public/empty-states/*.webp` files are a likely cause of the broken images in Preview.
