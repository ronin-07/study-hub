# Study Hub v0.5.2 — Polish 1 (Home + Study)

This incremental update applies the previously approved Home/Study design on `feature/v0.5.2-final-polish`. It does **not** include the future Tasks/Calendar, Focus/Resources, or global-sidebar batches.

## Included

- **Home:** the four metrics retain their shared top row. Course summaries and actionable priorities occupy the left dashboard column, with the seven-day agenda and **conditionally rendered** upcoming deadlines at right. One-course cards fill their available area, and neutral zero-overdue states avoid unnecessary warning colors. The existing course carousel, priority filters, navigation, PDF and Focus actions are preserved.
- **Study:** contextual semester subtitle, removal of repeated `Checklist only` labels from the weekly checklist (the Tasks visibility field is preserved), improved Course Library preview metadata for `Other` files, and consistent compact Study Tasks rows. Course Tasks filters: **All / This week / Exam prep**; `This week` means the selected teaching week. Menus explicitly distinguish **Remove from Tasks** from **Delete permanently**.
- **Exam Prep:** compact rows using the same activity data, completion progress, and an Add revision task action that reveals the input when selected.
- **Add Semester / Add Course:** consistent `Add semester`/`Add course` headings, full-width course title and goals fields, course code/weeks and semester/date pairs, scrollable short-screen dialog, and confirmation before discarding unsaved semester/course edits.

## Manual acceptance tests on Preview

1. Home with zero, one, two, and several scheduled courses: course summaries on the left, calendar on right at monitor width; responsive stacking on a laptop; course menu, Open course and carousel unchanged.
2. Home with zero and nonzero upcoming deadlines: empty deadline panel hidden; populated panel appears above Next 7 days. Zero Overdue has neutral styling; positive overdue remains visible and urgent.
3. Today's priorities: completion updates course progress, PDF opens, Focus starts and navigation remains correct. No redundant `Today` badge on every row.
4. Study Overview: selected semester subtitle is accurate, week/course progress stay independent, weekly checklist shows references/links/notes, and checklist-only setting remains editable even though the repeated badge is hidden.
5. Study Tasks: All vs selected teaching week vs Exam prep; verify week changes update the filtered rows; Focus, edit, schedule, remove from Tasks and permanent delete remain distinct. Test delete with disposable data only.
6. Exam Prep: on-demand creation, cancel, complete, progress, edit and reload preserve data; no duplicate task records.
7. Add/Edit Semester and Course: long title, optional fields, date validation, duplicate identifiers, loading state, Save and Cancel, dirty-form confirmation, keyboard focus. Check 768px-high laptop and mobile dialog scrolling.
8. Monitor, laptop, iPhone Safari, collapsed/expanded sidebar, light/dark theme; confirm no horizontal overflow or clipped action menus.
