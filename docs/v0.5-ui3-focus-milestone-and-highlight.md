# Study Hub v0.5 — UI Polish 3

Baseline: UI Polish 2 (including UI Polish 1a checkbox padding), on `feature/v0.5-tasks-calendar`.

## Changes

- **Study / Weekly learning checklist:** 14px horizontal insets and 10px rounding on *all* task rows (normal, overdue, completing). Overdue left accent uses inset shadow instead of a changing border width. The checkbox stays aligned when its completion highlight appears.
- **Home / Study courses:** Always reserve 10px horizontal padding and a rounded background around individual task rows. The completion highlight no longer touches the checkbox or card edge.
- **Course 100% milestone:** Extend the one-time success moment from 900ms to 2200ms. Add a clearly visible mint glow, gently emphasized percentage, progress sheen, and a temporary `COURSE COMPLETE` badge. The effect only runs on a transition from below 100% to 100%; it does not replay when a completed course is opened.
- **Focus target reached:** One ~2100ms ring halo when a running timed session first reaches its 25/50/90-minute target. Existing countdown/ring math, pause/resume, persistence, and the rule not to auto-end are unchanged. Stopwatch has no target celebration. Already-complete sessions do not replay on mount.
- **Accessibility:** All effects respect `prefers-reduced-motion` and all buttons/checkboxes preserve their existing focus treatment.

## Preview checklist

1. Study: check and uncheck one weekly activity, including overdue; confirm the mint row highlight and checkbox have consistent padding, no horizontal/vertical jump, and stable icon alignment.
2. Home: complete a course task; confirm the checkbox is inside the green rounded highlight, including with an Overdue pill.
3. Study: take a course with at least two actionable activities from 50% to 100%. Confirm the success effect is obvious for about 2.2 seconds and stops. Uncheck, recheck to confirm it can celebrate a new completion. Navigate away/back without re-triggering.
4. Focus: verify countdown mode displays `TARGET REACHED` at zero and gives one soft halo. The session must remain active until explicitly ended. The same must work after Pause/Resume and while browser tab has been backgrounded. Stopwatch must not celebrate at 60 seconds.
5. Check light/dark themes, narrow desktop/mobile, keyboard focus, and reduced-motion preference.

No backend, Firestore, auth, data model, or timer calculation code was changed in UI Polish 3. Do not merge into `main` without explicit approval.
