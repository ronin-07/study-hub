# Study Hub v0.5.1 — iPhone Safari and desktop sidebar refinements

## Scope

- Mobile top header stays in document flow instead of overlaying Home. Displays a compact Study Hub title, Quick Focus, refresh and theme controls; removes duplicate clock on small screens.
- Root HTML/body canvas and Safari `theme-color` follow Study Hub's light/dark theme. `viewport-fit=cover` plus safe-area padding protect the top content. Some iOS Safari native status/toolbar chrome is controlled by iOS and may not be fully tintable.
- Desktop sidebar has a one-click icon-only mode, saved in browser localStorage. The expanded sidebar can be dragged from its right border between 205px and 340px, subject to viewport width. Keyboard users can resize using Left/Right arrows (10px increments), Home restores default width, and double-click resets. The existing six items and account sign-out stay accessible.
- Mobile continues to use the existing bottom navigation; no second sidebar or extra mobile menu is introduced.

## Verification (required before Production)

1. **iPhone 17 Safari, dark mode:** reload Home and scroll to the top and bottom. Header must be in its own row, controls must not overlap greeting. Look for unwanted white overscroll around safe areas. Safari-native browser toolbar itself may remain a system-controlled shade.
2. **iPhone light mode:** switch theme, reload, confirm root/background and controls use light colors. Check Home, Study, Tasks, Calendar, Focus and Resources.
3. **iPhone Focus session running:** ensure active Focus control fits, pause/resume/end menus are usable, and Focus time is unaffected.
4. **iPhone bottom navigation:** all six buttons are reachable above Safari's address bar; check page scrolling and modal/dialog controls with keyboard showing.
5. **Laptop desktop:** toggle icon-only sidebar; hover/focus icons to identify labels. Expand again. Drag sidebar border left/right; test minimum/maximum, double-click reset, keyboard arrows, and Home to reset.
6. **Persistence:** refresh and navigate across tabs to verify collapsed/expanded state and custom width. Settings are device/browser-local, not synced through Firebase.
7. **27-inch 1440p:** verify default sidebar and approved spacious layout are unchanged; test both themes and compact mode without clipped workspace cards.
8. **Regression:** Google sign-in/sign-out, course navigation, activity edits, task completion, calendar, PDFs, and Focus session behavior.

Run `cd web && npm ci && npm test && npm run lint && npm run build`. In this environment `npm test` passed, but dependencies were incomplete so `npm run lint`/`npm run build` could not be certified.
