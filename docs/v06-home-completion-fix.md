# v0.6 — Home daily completion fix (after M3A)

Home now counts open overdue/current work and relevant completed-today work together. The progress denominator does not shrink when an overdue task is checked. Completed course cards remain for the local day; a collapsed Completed today section allows undo and respects the existing course/personal filters. Today's explicitly scheduled work retains its prior inclusion, even for legacy records without a completion timestamp. Unscheduled or future work is not counted just because it was completed today.

The backend records `completed_at` (UTC epoch seconds) on the existing item write when transitioning from incomplete to complete. Undo clears it; repeated completion and ordinary edits preserve it; recurring successors start with no completion date. Existing completed records with unknown timestamps are not backfilled or guessed. The frontend uses the browser's local calendar and existing clock refresh; optimistic completion and rollback include the timestamp. No additional Firestore queries or writes are introduced by Home or the timestamp. Existing data needs no migration. Deploy the updated backend and frontend together; no configuration changes or new dependencies.
