# v0.5.1 — Unified desktop workspace widths

## Design

Keep Study's approved responsive widths as the single layout standard for all six primary tabs:

- **Laptop / ordinary desktop:** content fills the available area, capped at 1,430px, with existing adaptive padding and typography.
- **Wide screens (viewport at least 1,800 CSS px):** every tab may expand to 1,780px (the existing Study width).
- **Narrow/mobile:** retain the existing single-column layouts, safe areas, and bottom navigation.

The shared `<main className="page-content">` already wraps Home, Study, Tasks, Calendar, Focus, and Resources. Previously, Home overrode its cap at 1,550px, and only Study expanded on very wide screens. Those exceptions are removed, and Home now uses the same horizontal page padding as Study and the other tabs, so page content aligns without duplicating UI components.

No font sizes, action placement, content order, data model, or page-specific card grids are changed.

## Test plan

1. Check Home, Study, Tasks, Calendar, Focus, and Resources at **2560×1440** and **1920×1080** with the same browser zoom and sidebar width. Their outer content edges should align.
2. At **1366×768** and **1536×864**, check all tabs remain compact and no controls, dates, task rows, PDFs, or Focus controls overflow.
3. Collapse and expand the sidebar at desktop width: each page should resize and recenter without horizontal scrolling.
4. On iPhone Safari, check the mobile topbar and bottom navigation remain correct.
5. Verify light and dark themes, PDF opening, task completion, and Focus controls as smoke tests.
6. Run `cd web && npm ci && npm test && npm run lint && npm run build` before deployment.

## Deployment

- Frontend-only CSS/tests/docs. No API, Firebase, Firestore, auth, Google Drive, or database changes.
- No Vercel environment-variable or project-setting changes; deploy the updated frontend from the normal Git workflow.
- A successful local or Vercel production build and browser-width checks are required before declaring the change verified.
