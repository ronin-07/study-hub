# Study Hub v0.5.1 — Adaptive layout polish

This update changes presentation only and keeps existing data, controls, accessibility labels, Focus timing, and the Mulberry Dusk visual language.

## Design

- Wide monitor (at least 1600 CSS px): existing 18px root typography and spacious layout are unchanged.
- Laptop (811–1599 CSS px): 17px root typography, narrower sidebar, shorter top bar, reduced card padding/gaps, and tighter Home, Study, Tasks, Calendar, Focus, and PDF workspace spacing.
- Small laptop (811–1279 CSS px): 16.5px root typography with more compact Study navigation and action placement.
- Study uses a CSS container query: when the usable course workspace is narrow, the checklist and resource cards stack rather than become unreadably cramped. Full details and actions remain available.
- Short laptops (up to 800 CSS px tall): reduce header/body spacing and the Focus dial's display size only; timer function is unchanged.
- Mobile (up to 810 CSS px): preserve existing bottom navigation and one-column layout, with 17px root typography and usable checklist action targets.

**Important:** Breakpoints use *CSS pixels*. Windows display scaling and browser zoom affect the effective viewport. A 2560 × 1440 monitor at typical scaling stays in the wide layout; a laptop at 125%/150% scaling may use the compact layout even at a high physical resolution.

## Local validation

```bash
cd web
npm ci
npm test
npm run lint
npm run build
```

The backend is unchanged, but the existing regression suite can be run with `cd backend && python -m pytest -q`.

## Manual Preview / Production checks

1. At effective browser widths 1100, 1250, 1366, 1536, 1920, and 2560 CSS px (normal zoom), verify Home, Study, Tasks, Calendar, Focus, Resources are balanced, with no horizontal overflow or missing actions.
2. On the laptop at normal Windows scaling, verify the Study sidebar is narrower, the card paddings/gaps are smaller, chapters/questions stay readable, long references wrap, and resource buttons work.
3. When the Study workspace gets narrow, verify the course checklist stacks above resources and notes/PDF links still work. Ensure icons remain visible and clickable.
4. On the external monitor, confirm the earlier spacious 18px layout looks unchanged.
5. On a short 1366×768 screen, verify the Focus timer fits with reasonable scrolling, its numbers and circular progress work, and dialogs can be scrolled without losing Save/Cancel.
6. At mobile widths 390/650/810, verify bottom navigation, Study rail, stacked cards, calendar dates, and dialog controls are accessible.
7. Test Google login, editing an existing study activity, completing/restoring a shared task, opening a PDF, and a Focus start/pause/end cycle. This CSS update should not change their behavior.
8. Verify both light and dark themes, keyboard focus indicators, and 200% browser zoom where reasonable.
