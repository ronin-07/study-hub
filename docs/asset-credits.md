Before making the repository public, record the creator, original source or generation workflow, relevant license/terms, required attribution and whether redistribution/modification is permitted for each asset. Replace any asset without adequate rights with an approved alternative. Verify license notices for third-party packages, fonts/icons and any screenshot contents. MIT covers code and documentation that the maintainer is entitled to license, not unverified third-party assets. Do not remove images solely because provenance is pending; the private app remains unchanged.

Application screenshots must use synthetic data and cleared assets; see [capture plan](screenshots/README.md). No private course PDFs, names, emails, tokens, real Drive folder paths, personal calendars or browser account details. Check image metadata and pixels before commit. Public release is blocked until the asset/ownership and final privacy audit is complete.
