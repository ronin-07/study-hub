# Study Hub v0.6 — Milestone 2: Exam Command Center

Applies on top of Milestone 1 and its UI polish, directly on main. No migration, new collection, or environment changes. Deploy the backend and frontend together.

- Upcoming exam cards on Home and derived Calendar exam events link directly to the course Exam Prep tab. Dates remain single-source course data. Archived courses are excluded from Home and Calendar.
- Exam-specific hero replaces only the weekly hero/selector while in Exam Prep. Coursework and revision progress remain separate. Optional exam start time, format, duration and location are saved with the course.
- Existing resources of type `exam_paper` appear automatically. Add via a URL or the existing Drive linking flow. Attempt history includes date, duration, optional percentage score and notes; deleting an attempt asks for confirmation. A stable request ID makes retries safe. The PDF viewer and bookmark path are unchanged. Attempt history is limited to 100 records per paper and 1000 characters of notes per attempt. Unlinking or changing type is blocked while attempts exist.
- Preparing a practice Focus session for a shared exam paper creates/reuses one linked course-wide revision task and opens the existing Focus setup (the user presses Start). Weekly-scoped papers can record attempts, but must be moved to the Course Library for this practice-task feature. Attempts and Focus sessions are intentionally not automatically combined.
- Exam Focus time is for sessions finished in the current local week and attributable to existing course-wide revision tasks only. No all-time estimate or artificial readiness score. If a revision task is removed, its historical sessions are not counted by this view.
- Weekly checklist category labels are hidden when the category is evident in the title; chapters/questions, notes, dates and resource links remain. Both existing themes are used.
