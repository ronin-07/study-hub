# Study Hub v0.3 — first real Goodnotes test

## Prerequisites

- Python API and Next.js UI running locally as described in `README.md`.
- An existing Goodnotes → Google Drive **PDF automatic backup** (already configured by the user).
- Google Cloud OAuth client credentials set in `backend/.env`. Keep `.env` **out of Git**.
- A DTU course created in Study Hub, with its correct code and week count.

## Browser smoke test

1. Open **Library** and **Connect my Drive**. Consent using your private Google account.
2. Browse to the existing Goodnotes backup folder (not the Drive root).
3. Click **Use this folder**, then **Scan for PDFs**.
4. Verify PDFs in nested folders are listed, with paths and modification dates.
5. Inspect a suggestion such as `02516/Week 10/...`. It must show course, week, kind, and confidence. No file should be linked without an explicit confirmation.
6. Click **Confirm match**, or set course/week/kind manually and choose **Link manually**.
7. In **Study**, open the selected course and week. The linked PDF should appear under **Week resources**.
8. Open the PDF within Study Hub; navigate to page 5 using the header control. Close and reopen **the linked resource**. It should reopen at the bookmarked page. Scrolling within the browser PDF itself is not automatically saved.
9. After adding a note to the corresponding document in Goodnotes and its backup finishing, re-scan. If Google Drive updates the same file ID, the linked resource should still work.
10. Confirm course study checklists, linked Tasks, and Focus still work.

## Known limitations / future milestones

- We have no real Google OAuth client credentials here, so live Drive and PDF retrieval still need this on-device test.
- The scanner is **manual**, bounded to 500 PDFs and 200 folders, and only stores metadata. Larger libraries require selecting a narrower folder; no background changes or Drive watcher is configured.
- Filename matching is conservative; it mainly recognizes course codes and week tokens (such as `Week 10`, `W10`, `L10`, `Lecture 10`). It will not reliably identify courses from arbitrary abbreviations or handwritten content. Always check suggestions.
- Google OAuth's External Testing mode may require reconnecting periodically, depending on scope and Google policy.
- PDF page navigation uses the browser-native PDF viewer with a page fragment. It is a **manual bookmark**, not reliable automatic last-scroll position tracking; the behavior may vary between browsers.
- DTU Learn API synchronization, native Goodnotes editing, PDF annotations, search/OCR, and background syncing are not part of v0.3.
