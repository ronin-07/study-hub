# Study Hub v0.5.2 — Polish 2.1 Tasks and Calendar corrections

## Scope

Small frontend-only follow-up to the approved v0.5.2 Polish 2 work. No backend contract, Firestore document, Focus timer, OAuth, or database changes.

### Global Tasks

- The list uses its available width at large monitor sizes. Task text stays on the left; a dedicated date column and the document/Focus/context actions align to the right.
- Row surfaces have consistent internal padding, subtle rounded borders, comfortable 36px action targets, and preserve deep-link highlights and completion animation.
- Responsive container-based rules move the date column beneath the task title on narrow layouts and move the action cluster below the metadata on small screens without losing any controls.
- An unscheduled task with a future deadline remains in **Unscheduled**, displaying both **Due [date]** and **Needs planning**. Scheduling is separate from a deadline and the existing Plan workflow is unchanged.

### Calendar

- Removed the global **New task** button from the Calendar header only; Global Tasks still has it.
- For a selected day with items, show a single **Plan task** action in the selected-day header.
- For an empty selected day, retain the existing photographic empty state and its **Add task** action, but do not show a duplicate header action.
- Both actions use the already-existing task form with the selected calendar date prefilled. Task drag-and-drop and due-date constraints are unchanged.

## Manual acceptance on Production after a successful local build

1. At your normal zoom on a 2560×1440 monitor, open Tasks → Today and Upcoming. Dates/actions should align against the right edge of the list; rows should use the full card width, without stretched text.
2. Resize the sidebar and test on a laptop: metadata and actions should reflow, never overlap or clip.
3. In Upcoming → Unscheduled, a due-only task must show **Due [date]** and **Needs planning**, plus its Plan action. Planning a task must not silently modify its due date.
4. Verify 3-dot menus, PDF shortcuts, Focus shortcuts, task checkboxes, and completion/deep-link highlights still work.
5. Calendar: there is no duplicate top-right New task button. With a populated date, its Selected Day panel shows **Plan task**. With an empty date, the photo empty state shows **Add task** and there is no duplicate header button.
6. Click either Calendar action while November 25 is selected: the task modal should default to November 25. Cancel or create a **disposable** test task; verify its date in Calendar and Tasks.
7. Check both light/dark themes, keyboard focus, iPhone Safari, and no horizontal overflow.
