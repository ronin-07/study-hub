# Study Hub v0.5.1 — readability and Study/Tasks hotfix

## Scope
- Increase sitewide rem typography (18px desktop, 17px narrow mobile). Weekly activity labels and chapters/pages are now separately legible.
- Edit a weekly activity's title, type, notes, chapter/pages, resource, dates, and Tasks visibility in the existing activity modal.
- Remove Quick Notes from Study Overview (no data deletion); retain notes as editable week activities.
- Show all shared course resources inside a keyboard-accessible, independently scrolling library card with a fixed visible footer.
- Support previous exam papers and exam solutions as shared resource types, including Drive linking.
- Separate **Remove from Tasks** from **Delete permanently** for course-week tasks. A new additive `hidden_from_tasks` boolean defaults to `false` for existing documents and overrides automatic task visibility without deleting their activity, dates, progress, or resource references.
