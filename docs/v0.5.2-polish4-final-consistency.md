# Study Hub v0.5.2 — Polish 4: Final global consistency

Apply this changed-files-only ZIP **on top of Polish 3** from a clean, updated `main`. This is a frontend-only release, not a data migration.

## Design and behavior changes

- Navigation: consistent **STUDY HUB / Page** breadcrumbs; six existing sidebar names unchanged; clearer collapsed/expanded control names; inactive links slightly brighter; Tasks badge explains its count; full profile name visible on hover or keyboard focus.
- Focus review: separate Hours / Minutes / Seconds controls keep exact-second accounting, but their number inputs no longer show ugly inset rectangular focus outlines/spinners. A single rounded focus treatment surrounds each field, with comfortable spacing before helper text and buttons.
- Focus main card: wider cards scale the ring, timer digits, selects, presets and controls more proportionally. Smaller laptop and mobile views retain compact sizing.
- Stopwatch: an open-ended session displays a continuous, static gradient ring with optional subtle ambient glow (not a percent-completion ring that restarts every minute). Pausing stops that motion; reduced-motion preferences remove it entirely. Countdown ring still represents remaining time. The elapsed time engine, pause/resume behavior, persistence and zero-duration protection are unchanged.
- Resources: search now has one rounded focus ring; the **Confirm link** explanation has breathing room. On desktop, the indexed PDF list scrolls independently below its search/filters while the right-hand Link document panel remains accessible. On smaller screens, the existing stacked select-and-scroll flow remains. Links continue to use the selected immutable Drive file ID and require an explicit click to confirm.

## Required manual tests before release

1. **Review dialog:** start then pause a 5–90 second stopwatch; click Finish & review; focus each Hours/Minutes/Seconds input with keyboard and mouse. Only one rounded field highlight appears, no browser spin arrows, and helper text never touches the cards or Save/Keep Paused buttons. Verify exact seconds and zero-duration discard.
2. **Stopwatch:** run past 59→60 and 119→120 seconds. Elapsed display rises continuously; the ring never visibly resets. Pause/resume and refresh; check no timer jumps. Turn on *Reduce motion* in the OS and confirm the ambient glow stops.
3. **Countdown:** start 25 minutes. The ring drains smoothly, does not wrap at one minute, and timed sessions still stop only when the user ends/reviews them.
4. **Focus responsive:** monitor, laptop, short-height laptop, iPhone Safari; inspect timer proportions, control alignment, and review modal scrolling in both themes.
5. **Resources:** select the last PDF of 19+ indexed items. While scrolling the PDF list, the linking form should remain visible on desktop. Search/filter should remain accessible; clearing/changing the selected PDF must not reuse the previous file's link. Preview, confirm, and saved link must match the exact Drive file ID.
6. **Resources mobile:** selecting a PDF in the narrow stacked layout should bring its linking form into view. Verify keyboard focus, labels and form button spacing; the entire page must remain scrollable.
7. **Sidebar:** test expand/collapse, resize, hover/keyboard profile name, Tasks count including zero, tab navigation and six existing titles. Breadcrumb reads `STUDY HUB / <page>`.
8. **Whole app:** Study checklist highlighting, Home summary, Tasks row actions, Calendar date selection, PDF viewer, light/dark contrast, and mobile bottom navigation. Confirm no horizontal overflow.

Use disposable tasks/document associations for destructive checks. Do not change important live coursework simply to test the layout.
