# Study Hub v0.5.1 — Overview information hierarchy polish

This is a frontend-only follow-up to the approved v0.5.1 UI design. The package is based on the most recently provided source archive with subsequent v0.5.1 changed-file ZIPs applied in release order; verify the diff against your latest GitHub `main` before applying.

## Design and scope

- **Home / Today's study courses:** show each course's code, title, week context, optional week topic, number of activities needing attention today, and progress. The individual task checkboxes were removed from course cards because they already appear in **Today's priorities**. The course CTA and contextual three-dot menu remain. One and two courses use narrower cards, avoiding unnecessary oversized tiles.
- **Study / Overview / This week's files:** show up to two week-specific resources with an open action, a View all link to the Week Resources tab, and Link week material for non-archived courses. Switching teaching weeks changes the preview.
- **Study / Overview / Course library:** show up to three course-wide references. Textbooks and notes are prioritized over exam files and slides, without claiming to track favorites or recent reads. The total file count and Open Course Library action remain. The preview is short rather than a second scrollable full library.
- **Full Course library and Week Resources tabs:** unchanged edit, unlink, Drive, and document management. No extra records or re-linking.
- **Progress:** the hero explicitly says **Course progress** and **course activities**; the checklist shows **Week N progress** and its own activity count.
- **Responsive:** moderately widen Study content on large monitors while preserving the laptop density rules; reduce Study header spacing slightly on laptops; maintain existing font sizes and mobile stacking.

## Testing

Run in `web/`: `npm ci`, `npm test`, `npm run lint`, `npm run build`. Run in `backend/`: `python -m pytest -q` when verifying the whole release.

On Vercel Preview (or Production after reviewing the direct-main release):

1. Home with one, two, and several courses: course cards display the correct topic and attention count without duplicate task checkboxes; Today's priorities still lets you complete tasks, open documents and start Focus.
2. Home with only overdue course tasks: wording indicates catch-up work and no false 'today' count. Course progress updates after completion and refresh.
3. Study Week 1 vs Week 2: 'This week's files' changes with the selected week while course reference preview remains the same.
4. Study with zero, one, two, and more than two weekly resources; verify View all, Link week material, and PDF opening.
5. Course library with zero, one, three, and more than three references; verify sensible reference-first ordering and View all access.
6. Verify editing/unlinking in dedicated tabs still works and a shared textbook linked to a weekly task still opens correctly.
7. Compare course total and selected-week total; they must be explicitly labeled and maintain existing completion calculations.
8. Validate Study and Home at 1366x768, 1536x864, 2560x1440, and iPhone Safari; test collapsed and expanded global sidebars and both light/dark themes.
9. Confirm no console errors and that resource links remain intact after a refresh and course switch.

## Production requirements

- No changes to Firebase Authentication, Firestore Rules, indexes, data schema/migration, or Google Drive OAuth.
- No backend API change, new secret, new environment variable, or Vercel configuration change.
- Deploy the updated frontend through existing Vercel Git integration.
- New behavior is UI-only; reverting the frontend release does not require Firestore rollback.
