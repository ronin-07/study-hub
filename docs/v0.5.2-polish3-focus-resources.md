# Study Hub v0.5.2 — Polish 3: Focus + Resources

## Design and behavior

**Focus**
- Keep the existing timer engine, optimistic updates, server-side session model and zero-duration deletion safeguard.
- Show **Focusing** or **Paused** consistently in the session badge; show the selected target rather than disabled preset buttons while active.
- Display short durations as seconds/minutes instead of `0.0 hours`. Total seconds in storage remain unchanged.
- Allow review by **hours / minutes / seconds**, clamped to the actual recorded duration; cancel keeps the session paused.
- Simplify the weekly goal: one readout/progress bar plus an edit affordance. The target remains stored locally, unchanged from v0.5.1.
- Add course, date and concise duration to recent session rows where a course is known.

**Resources**
- Compact connected-source summary, manual Scan PDFs, and optional expandable Drive-folder browser. Existing OAuth, scanning and APIs remain unchanged.
- Searchable file rows with **Unlinked**, **Suggested**, **Linked**, **All files** filters, retaining immutable Drive file IDs (never deduping by filename).
- Selected-file linking panel with explicit course, scope, week, material type and optional activity. Suggestions prefill fields but are **never linked automatically**.
- Course-library entry points preserve their course/week selection. Manual browsing does not inherit stale selections from a different file.
- Recently-linked files are guarded against double linking before the refreshed index arrives. The panel remains accessible on wide screens and moves above the list after a mobile selection.
- The existing native PDF reader and bookmark/zoom/navigation handling remain unchanged.

## Manual acceptance checklist

1. Focus Ready, Focusing, Paused: consistent status badge and topbar; clock doesn't jump during pause/resume.
2. Test 16 sec and 8 min examples: no misleading `0.0 hours`; recent-session duration displays correctly.
3. Review a countdown and stopwatch session; adjust hours/minutes/seconds, verify maximum, keep paused, then save. Verify 0-second discard and saved time in stats.
4. Close/reopen or refresh a running/paused timer; verify current behavior and task/course association remain intact.
5. Weekly focus target: show and hide editor, change value, refresh; test only local preference, not cross-device sync.
6. Resources: connect status, select folder, scan, refresh, search, switch all four filters; verify counts and no duplicate-name merges.
7. Select a suggested PDF, review metadata, change week/course, **confirm explicitly**, verify in correct Study resource section and open PDF.
8. Select a PDF without suggestion; manual linking must require a course. Switch between two PDFs and confirm fields do not leak to the next file.
9. After linking, confirm duplicate linking is blocked; inspect linked tab and preserve other course resources.
10. Open PDF viewer: page next/previous, bookmark restoration, zoom, expand, close and mobile/laptop view.
11. Test on laptop and 1440p monitor with expanded/collapsed sidebar, light/dark modes, and iPhone Safari responsive layout.

Use a disposable PDF/course relationship for mutation tests; code rollback does not undo Firestore writes.
