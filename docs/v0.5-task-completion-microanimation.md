# Study Hub v0.5 — UI Polish 1: Task completion

Incremental UI-only change based on the stable Phase D code, before the larger visual-polish bundle.

## Behavior

- On the first click, the checkbox becomes checked immediately and the existing targeted `PATCH /api/items/{id}` starts immediately. No artificial network delay.
- An optimistic completed row stays visible for at least **750 ms** for the mint checkmark, text strikethrough, and brief acknowledgment.
- The exit occupies another **150 ms**, making the normal path approximately **900 ms** total.
- The exit waits for successful server confirmation; slow requests hold the completed appearance until the API succeeds. Errors roll back and cancel all animation timers.
- Only lists that filter out completed rows animate an exit. Week Overview (All), Study Tasks, Exam Prep, PDF checklists, and Calendar's scheduled rows keep completed items, so they do not disappear and reappear.
- The snapshot stays canonical. A temporary read-only task projection retains rows visually without creating duplicate records or delaying recurrence writes.
- Native checkboxes remain keyboard accessible. `prefers-reduced-motion: reduce` bypasses the hold and exit; CSS animations/transitions are disabled.
- Timer cleanup runs on auth changes and component unmount.

## Preview verification

1. Complete a Home priority and a course-card task; the task should stay mint/checked briefly, then leave the active list.
2. Complete a task in Tasks Today or Upcoming, including recurring tasks; it should move to Completed after the animation. Verify the next recurrence appears once.
3. Complete a Week activity with filter All; the row must **remain** completed without fading out and reappearing. With Planned/Due filter, it must exit after the animation.
4. Complete a task in the Calendar and PDF reader; it should stay checked when that view includes completed items.
5. Test a slow or failed `PATCH`; the row must remain visible while pending and roll back with the existing error if the save fails.
6. Test rapid double clicks, Home-to-Study navigation during completion, light/dark mode, and reduced-motion preference.
7. Verify all existing pages and Focus timer are unaffected.
